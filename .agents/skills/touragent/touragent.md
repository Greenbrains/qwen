# Навык: Маркетинг (Marketing Skills)

Набор под-навыков для продуктового маркетинга: контекст продукта, конкурентный
ландшафт, копирайтинг, генерация презентаций, SEO. Каждый под-навык имеет
чёткий рабочий процесс и **всегда** возвращает файл в папке `output/`.

## Когда использовать

- «Проанализируй конкурентов» / «сделай конкурентный анализ»
- «Напиши текст для лендинга» / «сделай копирайт»
- «Сделай презентацию PPTX» / «слайды для питча»
- «Проработай SEO» / «подбери ключевые слова»
- «Создай контекст продукта» / «определи ЦА и ICP»

## Общие правила (обязательны для всех под-навыков)

1. **Файлы — только через `execute_code`.** Никогда не выводи длинные таблицы,
   презентации или документы в текстовом виде Markdown. Всегда генерируй
   `.xlsx` / `.pptx` / `.docx` через `execute_code` и возвращай путь из ответа
   инструмента (формат `output/<имя>_<id>.<ext>`).
2. **Веб-данные — только через `web_search`.** Внутри `execute_code` интернета
   нет. Собери факты/цифры через `web_search` сначала, потом передай в код как
   готовые значения.
3. **Никаких выдумок.** Если данных нет в источниках — пиши «н/д» и URL
   источника. Не придумывай цены, объёмы рынка, отзывы.
4. **Каталог под-навыков читай ниже.** Не вызывай `load_skill("presentation")`
   — такого отдельного навыка нет. Все под-навыки описаны прямо в этом файле.
5. **Экономь токены:**
   - Не вызывай под-навыки, которые не нужны для текущего запроса.
   - Не перечитывай `SKILL.md` повторно.
   - Сохраняй результаты в `output/` — не копируй в ответ.

## Под-навык: `product-marketing-context`

**Когда использовать:** «создай контекст продукта», «кто моя ЦА», «определи ICP»,
«обнови позиционирование». Создаёт файл `.agents/product-marketing-context.md`,
на который ссылаются остальные под-навыки.

### Рабочий процесс

**Шаг 1.** Проверь, существует ли `.agents/product-marketing-context.md` через
`file_read`. Если есть — кратко изложи, спроси, какие разделы обновить. Если
нет — предложи авто-черновик по данным из запроса.

**Шаг 2.** Собери информацию по 12 разделам:
1. Обзор продукта (1 строка + 2–3 предложения + категория + тип + цена)
2. Целевая аудитория (тип компаний, ЛПР, основной сценарий, JTBD)
3. Персоны (B2B: Пользователь / Чемпион / ЛПР / Финансовый / Технический)
4. Проблемы и болевые точки
5. Конкурентный ландшафт (прямые / вторичные / косвенные)
6. Дифференциация
7. Возражения и анти-персоны
8. Динамика переключения (JTBD: Push/Pull/Habit/Anxiety)
9. Язык клиентов (дословные фразы + стоп-слова + глоссарий)
10. Голос бренда
11. Доказательства
12. Цели

**Шаг 3.** Сохрани через `file_write` в `.agents/product-marketing-context.md`.

**Шаг 4.** Резюме: какие разделы заполнены, какие требуют уточнения.

## Под-навык: `competitive-landscape`

**Когда использовать:** «проанализируй конкурентов», «сравни с конкурентами»,
«кто мои конкуренты», «таблица конкурентов».

### Рабочий процесс

**Шаг 1.** Сформулируй одной фразой: продукт / ЦА / цена. Определи «полку» —
как клиенты ищут такой продукт.

**Шаг 2.** Найди 5–7 конкурентов через `web_search`. Для каждого зафиксируй:
`Название · Сайт · Тип · ЦА · Сильные · Слабые · Цена · URL`.

**Шаг 3.** Собери XLSX через `execute_code` с точным рецептом кода:

```python
try:
    import openpyxl
    from openpyxl.styles import Font, PatternFill
except ImportError:
    import subprocess
    subprocess.run(["pip", "install", "-q", "openpyxl"])
    import openpyxl
    from openpyxl.styles import Font, PatternFill

wb = openpyxl.Workbook()

# Лист 1: Конкуренты
ws1 = wb.active
ws1.title = "Конкуренты"
headers = ["Название", "Сайт", "Тип", "ЦА", "Сильные", "Слабые", "Цена", "Источник"]
ws1.append(headers)
for h in headers:
    ws1.cell(1, headers.index(h)+1).font = Font(bold=True)

# ВСТАВЬ ДАННЫЕ ИЗ ШАГА 2 как список словарей
competitors = [
    # {"name": "...", "site": "...", "type": "прямой", ...},
]
for c in competitors:
    ws1.append([c.get("name",""), c.get("site",""), c.get("type",""),
                c.get("audience",""), c.get("strengths",""),
                c.get("weaknesses",""), c.get("price",""), c.get("url","")])

# Лист 2: Сводка
ws2 = wb.create_sheet("Сводка")
ws2.append(["Раздел", "Вывод"])
ws2.append(["5. Конкурентный ландшафт", "<вывод по прямым/вторичным/косвенным>"])
ws2.append(["6. Дифференциация", "<в чём продукт сильнее>"])

wb.save("competitors_analysis.xlsx")
print("competitors_analysis.xlsx")
```

**Шаг 4.** Верни путь из ответа `execute_code` (`output/competitors_analysis_<id>.xlsx`)
и резюме из 3–5 пунктов.

## Под-навык: `copywriting`

**Когда использовать:** «напиши заголовки», «текст для лендинга», «email»,
«рекламное объявление», «сделай копирайт».

### Рабочий процесс

**Шаг 1.** Бриф: формат / ЦА / целевое действие (CTA) / тон / ограничения.

**Шаг 2.** (Опционально) Собери факты через `web_search`. Сохраняй URL.

**Шаг 3.** Напиши варианты:
- Короткие форматы — 5–7 вариантов под разные углы (боль, выгода, любопытство,
  соц. доказательство, срочность).
- Длинные форматы — PAS или AIDA, одна секция = одна мысль.

**Шаг 4.** Сохрани через `execute_code`:
- По умолчанию — Markdown (заголовок + варианты + обоснование)
- DOCX — только если явно просит пользователь

```python
# Для Markdown
content = """# Заголовок лендинга
...
"""
with open("copy_landing.md", "w", encoding="utf-8") as f:
    f.write(content)
print("copy_landing.md")

# Для DOCX (только при явном запросе)
try:
    from docx import Document
except ImportError:
    import subprocess
    subprocess.run(["pip", "install", "-q", "python-docx"])
    from docx import Document
doc = Document()
doc.add_heading("Заголовок", 0)
doc.save("copy_ads.docx")
print("copy_ads.docx")
```

**Шаг 5.** Верни путь + рекомендованный вариант + обоснование + идею для A/B.

## Под-навык: `presentation` ⭐ (PPTX)

**Когда использовать:** «сделай презентацию», «PPTX», «PowerPoint», «pitch
deck», «слайды для клиента», «презентация продукта».

### ВАЖНО
- **ВСЕГДА** возвращай `.pptx`, а НЕ Markdown или текст.
- **НИКОГДА** не пиши `open("presentation.md", "w")` вместо python-pptx.
- **НЕ** вызывай `load_skill("presentation")` — такого отдельного навыка нет.

### Рабочий процесс

**Шаг 1.** Бриф презентации: тема, количество слайдов (8–12 по умолчанию), ЦА,
тон. Если пользователь не указал — уточни или используй разумные дефолты.

**Шаг 2.** (Опционально) Собери факты через `web_search`: цифры рынка,
статистика, цитаты. Сохраняй URL источников.

**Шаг 3.** Сгенерируй PPTX через `execute_code` — **строго по рецепту ниже**:

```python
try:
    from pptx import Presentation
    from pptx.util import Inches, Pt
    from pptx.enum.text import PP_ALIGN
    from pptx.dml.color import RGBColor
except ImportError:
    import subprocess
    subprocess.run(["pip", "install", "-q", "python-pptx"])
    from pptx import Presentation
    from pptx.util import Inches, Pt
    from pptx.enum.text import PP_ALIGN

prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.5)

# Цветовая схема
TITLE_COLOR = RGBColor(0x1A, 0x56, 0xDB)  # синий
TEXT_COLOR = RGBColor(0x2D, 0x2D, 0x2D)    # тёмно-серый
ACCENT_COLOR = RGBColor(0xFF, 0x6B, 0x35)  # оранжевый CTA

def add_title_slide(prs, title, subtitle):
    slide = prs.slides.add_slide(prs.slide_layouts[6])
    txBox = slide.shapes.add_textbox(Inches(1), Inches(2.5), Inches(11), Inches(2))
    tf = txBox.text_frame
    tf.text = title
    tf.paragraphs[0].font.size = Pt(54)
    tf.paragraphs[0].font.bold = True
    tf.paragraphs[0].font.color.rgb = TITLE_COLOR
    tf.paragraphs[0].alignment = PP_ALIGN.CENTER
    sub = slide.shapes.add_textbox(Inches(2), Inches(4.5), Inches(9), Inches(1))
    sub.text_frame.text = subtitle
    sub.text_frame.paragraphs[0].font.size = Pt(24)
    sub.text_frame.paragraphs[0].alignment = PP_ALIGN.CENTER

def add_content_slide(prs, title, bullets):
    slide = prs.slides.add_slide(prs.slide_layouts[6])
    title_box = slide.shapes.add_textbox(Inches(0.8), Inches(0.5), Inches(11), Inches(1))
    title_box.text_frame.text = title
    title_box.text_frame.paragraphs[0].font.size = Pt(36)
    title_box.text_frame.paragraphs[0].font.bold = True
    title_box.text_frame.paragraphs[0].font.color.rgb = TITLE_COLOR
    body_box = slide.shapes.add_textbox(Inches(1), Inches(1.8), Inches(11), Inches(5))
    tf = body_box.text_frame
    tf.word_wrap = True
    for i, bullet in enumerate(bullets):
        p = tf.paragraphs[0] if i == 0 else tf.add_paragraph()
        p.text = bullet
        p.font.size = Pt(22)
        p.font.color.rgb = TEXT_COLOR
        p.space_after = Pt(12)

# === СОДЕРЖИМОЕ ПРЕЗЕНТАЦИИ ===
# Замени на данные из брифа пользователя!
slides = [
    ("Титульный", "Заголовок презентации", "Подзаголовок / слоган"),
    ("Проблема", [
        "Боль #1 клиента",
        "Боль #2 клиента",
        "Почему текущие решения не работают",
    ]),
    ("Решение", [
        "Как мы решаем проблему",
        "Ключевое отличие",
    ]),
    ("Как это работает", [
        "Шаг 1: ...",
        "Шаг 2: ...",
        "Шаг 3: ...",
    ]),
    ("Преимущества", [
        "✓ Преимущество 1",
        "✓ Преимущество 2",
        "✓ Преимущество 3",
        "✓ Преимущество 4",
    ]),
    ("Цена", [
        "Тариф 1: ... ₽/мес",
        "Тариф 2: ... ₽/мес",
        "Бесплатный пробный период: 7 дней",
    ]),
    ("Кейсы", [
        "Кейс 1: компания X, результат Y",
        "Кейс 2: компания Z, результат W",
    ]),
    ("Команда", [
        "Основатели и ключевые люди",
        "Экспертиза",
    ]),
    ("Roadmap", [
        "Q3 2026: ...",
        "Q4 2026: ...",
        "2027: ...",
    ]),
    ("CTA", [
        "Попробуйте бесплатно 7 дней",
        "Без привязки карты",
        "support@example.com",
    ]),
]

# Первый слайд — титульный
add_title_slide(prs, slides[0][1], slides[0][2])

# Остальные — контентные
for title, bullets in slides[1:]:
    add_content_slide(prs, title, bullets)

prs.save("presentation.pptx")
print("presentation.pptx")
```

**Шаг 4.** Дождись ответа `execute_code` с путём
`output/presentation_<id>.pptx` и верни его пользователю.

**Шаг 5.** Финальный ответ в формате:

```markdown
✅ Презентация готова!

📄 **Файл:** `output/presentation_<id>.pptx`

📊 **Содержание (N слайдов):**
1. Титульный — <краткое описание>
2. Проблема — <краткое описание>
3. Решение — <краткое описание>
...
```

### Жёсткие правила

- ❌ **НЕЛЬЗЯ** возвращать презентацию текстом вместо PPTX.
- ❌ **НЕЛЬЗЯ** пропускать `execute_code` — без него файла не будет.
- ❌ **НЕЛЬЗЯ** хардкодить путь `output/...` внутри кода — `execute_code` сам
  скачает артефакт и вернёт путь.
- ✅ Кириллица работает без дополнительных шрифтов.
- ✅ Если пользователь дал готовое содержание — используй его как есть.

## Под-навык: `seo`

**Когда использовать:** «подбери ключевые слова», «сделай SEO», «контент-план»,
«мета-теги», «семантика».

### Рабочий процесс

**Шаг 1.** Определи тему и 3–5 seed-запросов на языке клиентов.

**Шаг 2.** Расширь ключи через `web_search`: смежные запросы, «люди также
спрашивают», типы ранжирующихся страниц. Для каждого зафиксируй:
`Запрос · Кластер · Интент · Тип страницы · URL`.

**Шаг 3.** Сгруппируй в кластеры. Для каждого: целевая страница, интент, тип
контента, черновой title/description, H2/H3, внутренние ссылки.

**Шаг 4.** Собери XLSX через `execute_code` (рецепт как в `competitive-landscape`,
но с тремя листами: `Ключевые слова`, `Кластеры`, `Контент-план`).

**Шаг 5.** Верни путь + резюме из 3–5 пунктов: топ-кластеры для старта,
доминирующий интент, с каких страниц начать.

### Правила качества

- Объёмы поиска указывай только со ссылкой на источник; иначе — оценка
  `high/medium/low` с обоснованием.
- Не смешивай несколько интентов в одном кластере.
- К цифрам всегда прикладывай URL.

## 💡 Общие советы

1. **Начинай с брифа.** Не придумывай недостающее — уточни у пользователя.
2. **Будь конкретен.** «Какая #1 проблема приводит клиента к вам?».
3. **Фиксируй дословный язык клиентов.** Это ценнее отполированных описаний.
4. **Проверяй по ходу.** Резюмируй раздел и подтверждай у пользователя.
5. **Пропускай неприменимое.** Например, Персоны для B2C часто не нужны.
6. **Разделяй факты и выводы.** В XLSX помечай, где интерпретация.
