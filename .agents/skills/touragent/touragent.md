# Навык: Турагент (Tour Agent)

## Описание

Специализированный навык для подбора туров и путешествий. Помогает пользователю:
- Подобрать перелёт/проезд (самолёт, поезд, электричка, автобус)
- Найти и рекомендовать отели по направлению с учётом отзывов
- Изучить варианты трансфера и сравнить стоимость
- Сформировать календарь цен на перелёт и ЖД билеты
- Проверить наличие билетов на нужные даты

## Когда использовать

Используй этот навык, когда пользователь запрашивает:
- "Подбери тур в [город/страну]"
- "Найти билеты из Москвы в Сочи"
- "Посоветуй отель на побережье"
- "Сравни цены на самолёт и поезд"
- "Покажи календарь цен на сентябрь"
- "Какие есть варианты трансфера до отеля"

## Рабочий процесс

### Шаг 1: Уточнение параметров поездки

Запроси у пользователя ключевую информацию:
1. **Направление**: город/страна вылета и прибытия
2. **Даты**: желаемые даты поездки (или период для поиска)
3. **Количество путешественников**: взрослые, дети
4. **Бюджет**: ограничения по стоимости (если есть)
5. **Предпочтения**: тип транспорта, класс обслуживания, удобства в отеле

### Шаг 2: Поиск вариантов перелёта/проезда

Используй MCP-инструменты Туту для поиска:

**Авиабилеты:**
```
search_avia(origin="Москва", destination="Сочи", departure_date="2025-09-01", passengers=2)
```

**Ж/Д билеты:**
```
search_rail(from_city="Москва", to_city="Сочи", departure_date="2025-09-01", passengers=2)
```

**Мультимодальный поиск (сравнение всех вариантов):**
```
search_multitransport(from_city="Москва", to_city="Сочи", departure_date="2025-09-01", adults=2, optimize_for="price")
```

**Электрички (для коротких маршрутов):**
```
search_etrain(origin="Москва", destination="Подмосковье", departure_date="2025-09-01")
```

**Автобусы:**
```
search_bus(origin="Москва", destination="Минск", departure_date="2025-09-01")
```

### Шаг 3: Формирование календаря цен

Для формирования календаря цен выполни поиск на несколько дат:
1. Выбери диапазон дат (например, 1-10 сентября)
2. Для каждой даты вызови `search_avia` и `search_rail`
3. Собери результаты в таблицу с колонками: Дата | Авиабилеты (от) | ЖД (от) | Примечания
4. Визуализируй через execute_code (matplotlib) или представь в виде Markdown-таблицы

### Шаг 4: Поиск отелей

Используй инструмент `search_hotels`:
```
search_hotels(city_name="Сочи", check_in="2025-09-01", check_out="2025-09-08", guests=2)
```

Для детализации предложения:
```
get_offer_details(offer_id="<ID_оффера>", view="full")
```

**Рекомендации по отелям:**
- Сортируй по рейтингу и отзывам
- Учитывай правила отмены
- Обращай внимание на удобства (Wi-Fi, бассейн, питание)
- Проверяй расстояние до пляжа/центра

### Шаг 5: Сравнение вариантов трансфера

Сравни все доступные варианты:
| Тип транспорта | Время в пути | Стоимость | Комфорт | Примечания |
|---------------|-------------|-----------|---------|------------|
| Самолёт       | 2.5 часа    | от 15000₽ | Высокий | Быстрее всего |
| Поезд         | 24 часа     | от 5000₽  | Средний | Можно спать |
| Автобус       | 20 часов    | от 3500₽  | Низкий  | Дешевле |

## Инструменты MCP Туту

Навык использует следующие MCP-инструменты через сервер Туту:

### Поисковые инструменты
- `search_avia` — авиабилеты
- `search_rail` — ж/д билеты
- `search_bus` — автобусы
- `search_etrain` — электрички
- `search_hotels` — отели
- `search_multitransport` — мультимодальный поиск

### Инструменты детализации
- `get_offer_details` — детали оффера
- `get_rail_seatmap` — схема вагона

### Инструменты действий
- `create_checkout_link` — ссылка на оплату

### Справочные инструкции
- `get_avia_instructions` — правила для авиа
- `get_rail_instructions` — правила для ЖД
- `get_hotels_instructions` — правила для отелей

## Подключение к MCP-серверу Туту

Для работы навыка необходимо подключение к MCP-серверу:

```python
from tools.mcp import AsyncMCPClient, get_settings

settings = get_settings()
client = AsyncMCPClient(
    url="https://mcp.tutu.ru/sse",
    settings=settings
)

# Инициализация
async with aiohttp.ClientSession() as session:
    await client.initialize(session)
    tools = await client.list_tools(session)
    
    # Поиск билетов
    result = await client.call_tool(
        "search_avia",
        {"origin": "Москва", "destination": "Сочи", "departure_date": "2025-09-01"}
    )
```

## Важные замечания

1. **Даты всегда в формате YYYY-MM-DD**
2. **Коды аэропортов IATA**: SVO (Шереметьево), DME (Домодедово), VKO (Внуково), AER (Сочи)
3. **Не передавай return_date** в search_multitransport — только departure_date!
4. **Для create_checkout_link** поля из checkout_ref передаются на верхнем уровне arguments
5. **Проверяя отзывы**, обращай внимание на свежие комментарии (последние 3 месяца)
6. **При формировании календаря цен** используй execute_code для визуализации графиков

## Пример диалога

**Пользователь**: "Найди билеты из Москвы в Сочи на начало сентября, покажи календарь цен"

**Агент**: 
1. Загружает навык: `load_skill(skill_name="touragent")`
2. Уточняет: "На какие даты именно? Сколько пассажиров?"
3. Выполняет поиск на 1-10 сентября через `search_avia` и `search_rail`
4. Строит календарь цен через `execute_code` с matplotlib
5. Показывает таблицу и график, рекомендует лучшие даты
