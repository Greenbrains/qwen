# Каталог навыков (Skills Catalog)

Это файл-роутер для ИИ-агента. Агент читает его, чтобы определить, какой навык
(Skill) загрузить под запрос пользователя. Загружай навык через
`load_skill(skill_name="<имя>")`. Чтобы перечитать этот каталог в любой момент —
вызови `load_skill()` без аргумента.

## Доступные навыки

| Название навыка | skill_name | Когда использовать |
| :--- | :--- | :--- |
| Виртуальные машины Cloud.ru | `cloudru-vm` | Создание, управление, удаление ВМ, дисков, сетей и групп безопасности в Cloud.ru. Работа с SSH/SCP и Compute API. |
| Настройка аккаунта Cloud.ru | `cloudru-account-setup` | Первоначальная настройка аутентификации: получение и проверка переменных окружения (`CP_CONSOLE_KEY_ID`, `CP_CONSOLE_SECRET`, `PROJECT_ID`). |
| Автоматизация браузера | `browser-use` | Автоматизация браузера: headless Chromium, клики, ввод текста, скриншоты, работа с сессиями, туннели Cloudflare, профили Chrome. |
| Маркетинговые навыки | `marketingskills` | Любые задачи продуктового маркетинга: позиционирование, ICP/целевая аудитория, **анализ конкурентов и конкурентного ландшафта**, дифференциация, язык клиентов, копирайтинг, SEO, growth. Внутри есть под-навыки, в т.ч. воспроизводимый анализ конкурентов с выгрузкой в таблицу. |
| Турагент | `touragent` | Подбор туров и путешествий: поиск авиа/жд билетов, отелей, трансферов. Сравнение стоимости разных видов транспорта, формирование календаря цен, рекомендации отелей по отзывам. Работает через MCP-сервер Туту. |

## Правила использования

1. **Загружай только нужный навык.** Прочитай каталог, выбери один навык по колонке «когда использовать» и загрузи только его.
2. **Следуй тексту навыка буквально.** После загрузки действуй по его рабочему процессу, шагам, разделам и требованиям к формату вывода. Не додумывай детали за навык.
3. **Проверяй зависимости.** Убедись, что заданы переменные окружения, если навык их требует.
4. **Соблюдай безопасность.** Никогда не выводи в чат значения секретных ключей или токенов.
