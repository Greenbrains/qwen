# Каталог навыков (Skills Catalog)

Файл-роутер для ИИ-агента. Агент читает его, чтобы понять, какой навык (Skill)
загрузить под запрос пользователя. Загрузка: `load_skill(skill_name="<имя>")`.
Чтобы перечитать каталог — `load_skill()` без аргумента.

## Доступные навыки

| Название навыка | skill_name | Когда использовать |
| --- | --- | --- |
| General | `general` | Простые разговоры, приветствия, вопросы без специализации. **НЕ использует тяжёлые инструменты** (MCP, веб-поиск, код). |
| ЖД Транспорт | `rail` | ЖД билеты: поезда дальнего следования, электрички. Работает через MCP-сервер Туту (`tutu_call`). |
| Авиаперелёты | `avia` | Авиабилеты: прямые рейсы, пересадки. Работает через MCP-сервер Туту (`tutu_call`). |
| Отели | `hotels` | Отели, гостиницы, апартаменты. Работает через MCP-сервер Туту (`tutu_call`). |
| Планировщик маршрутов | `trip_planner` | Мультимодальные путешествия: сравнение транспорта, «как добраться». Работает через MCP-сервер Туту (`tutu_call`). |
| Маркетинг | `marketing` | Продуктовый маркетинг: анализ конкурентов, копирайтинг, SEO, презентации PPTX. Использует `web_search`, `execute_code`. |

## Правила использования

1. **Загружай только нужный навык.** Выбери один по колонке «когда использовать».
2. Следуй тексту навыка буквально — по его рабочему процессу и формату вывода.
3. **Под-навыки** (`presentation`, `competitive-landscape`, `copywriting`, `seo`,
   `product-marketing-context`) описаны **ВНУТРИ** `marketing.md`.
   Отдельных файлов для них **НЕТ**: `load_skill("presentation")` вернёт ошибку.
   Загружай только `marketing` и читай нужный раздел внутри него.
4. Если текст навыка уже встроен в системный промпт — **НЕ вызывай `load_skill`
   с этим же именем повторно** (это лишний расход токенов).
5. Соблюдай безопасность — никогда не выводи значения секретов/токенов в чат.
6. **Архитектура субагентов:** каждый навык загружает только свои инструменты (3-5 вместо 17),
   что экономит токены и ускоряет ответ на простые запросы.
