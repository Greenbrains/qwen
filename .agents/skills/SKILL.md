# Каталог навыков (Skills Catalog)

Этот файл служит маршрутизатором для ИИ-агента. Используйте его для определения того, какой конкретный навык (Skill) необходимо загрузить для выполнения запроса пользователя.

| Название навыка | Файл | Когда использовать |

| **cloudru-vm** | `cloudru-vm/cloudru-vm.md` | Создание, управление, удаление ВМ, дисков, сетей и групп безопасности в Cloud.ru. Работа с SSH/SCP и API Compute. |

## Правила использования

1. **Не загружайте все навыки сразу.** Читайте этот каталог, определите нужный навык и загрузите только его содержимое.
2. **Проверяйте зависимости.** Перед выполнением действий убедитесь, что у пользователя настроены необходимые переменные окружения (указаны в каждом навыке).
3. **Соблюдайте безопасность.** Никогда не выводите в чат значения секретных ключей или токенов.
