# Навык: Планировщик Маршрутов (Trip Planner Agent)

## Описание
Специализированный навык планирования мультимодальных путешествий: сравнение видов транспорта (авиа/ЖД/автобусы), построение сложных маршрутов с пересадками.
Работает через MCP-сервер Туту, вызываемый **единым инструментом** `tutu_call`.

## Когда использовать
- «Как добраться из Москвы в Сочи?»
- «Сравни самолёт и поезд по времени и цене»
- «Маршрут с пересадками»
- «Что дешевле — лететь или ехать поездом?»

## Как вызывать инструменты Туту (ВАЖНО)
Все инструменты Туту вызываются через прокси `tutu_call(tool, args_json)`:
- `tool` — имя инструмента из «Каталога инструментов Туту» в системном промпте;
- `args_json` — аргументы **строкой JSON**.

### ⚠️ Точные имена полей для МУЛЬТИМАРШРУТОВ
- Поля отправления/прибытия — **`origin` / `destination`**;
- Число взрослых — **`adults`**;
- **`departure_date` обязателен** — сначала уточни дату у пользователя;
- Для мультимодального поиска используй `search_multitransport`.

### Примеры вызовов
```
tutu_call(tool="search_multitransport",
          args_json='{"origin":"Москва","destination":"Сочи","departure_date":"2026-08-15","adults":2}')

tutu_call(tool="get_offer_details",
          args_json='{"offer_id":"12345","view":"compact"}')

tutu_call(tool="create_checkout_link",
          args_json='{"offer_id":"12345"}')
```

## Рабочий процесс

### Шаг 1: Уточнение параметров
Спроси недостающее: откуда/куда, **дату начала поездки**, число путешественников, предпочтения (скорость vs цена, прямой рейс vs пересадки).

### Шаг 2: Мультимодальный поиск
Вызови `search_multitransport` для сравнения всех доступных видов транспорта. Если дата не указана — НЕ вызывай поиск, сначала спроси.

### Шаг 3: Сравнение вариантов
Проанализируй результаты: время в пути, количество пересадок, общая стоимость. Отфильтруй по критериям пользователя (например, «прибытие до 18:00»).

### Шаг 4: Детали и оформление
- Детали оффера: `tutu_call(tool="get_offer_details", args_json='{...}')` с `view="compact"` для экономии токенов.
- Ссылка на оформление: `tutu_call(tool="create_checkout_link", args_json='{...}')`.

### Шаг 5: Итоговое предложение (Markdown)
- 🚌/🚆/✈️ Варианты транспорта (сравнение по времени и цене)
- ⏱️ Время в пути, пересадки
- 💰 Итого на всех пассажиров
- 🔗 Ссылка на оформление (если запрошено)

## Правила экономии токенов
1. В `get_offer_details` используй `view="compact"`.
2. Переиспользуй уже полученные offer_id, не дублируй поиск.
3. Сначала один вид транспорта; мультипоиск — только если нужно сравнение.

## Важные замечания
- Даты — всегда `YYYY-MM-DD`. Сегодняшняя дата есть в системном промпте.
- Не выдумывай offer_id, цены и ссылки — используй только то, что вернул `tutu_call`.
