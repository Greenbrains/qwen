# 🛠 Шпаргалка: Извлечение и обработка навыков (Skills)

## Шаг 1: Извлечение текста из браузера
1. Откройте страницу навыка в браузере.
2. Нажмите **F12** (или Ctrl+Shift+I), перейдите во вкладку **Console**.
3. Если браузер просит разрешение, введите `allow pasting` и нажмите Enter.
4. Скопируйте код ниже, вставьте в консоль и нажмите **Enter**.

```javascript
const c = document.querySelector('main') || document.querySelector('article') || document.body; 
const t = "=== START SKILL ===\n" + c.innerText + "\n=== END SKILL ==="; 
console.log(t); 
try { copy(t); console.log("✅ Текст также автоматически скопирован в буфер обмена!"); } catch(e) { console.log("⚠️ Скопируйте текст из консоли вручную (от START до END)"); }
```

## Шаг 2: Очистка и форматирование через ИИ
Скопируйте вывод из консоли (всё, что между `=== START SKILL ===` и `=== END SKILL ===`) и отправьте ИИ со следующим промптом:

---
**📋 Скопируйте этот промпт и вставьте свой текст внизу:**

```text
Я извлек сырой текст навыка из веб-страницы через консоль браузера. Выполни следующие задачи:

1. Очистка: Удали весь визуальный мусор (хлебные крошки, цены, кнопки "Copy", номера строк, боковое меню).
2. Форматирование: Приведи текст к чистому, структурированному Markdown. Сохрани все блоки кода (bash/python), заголовки, списки и важные предупреждения (⚠️).
3. Перевод: Если текст навыка на английском, то переведи его на русский язык, структурированному Markdown. Сохрани все блоки кода (bash/python), заголовки, списки и важные предупреждения (⚠️).
4. Путь: Определи логичное имя навыка (например, `browser-use`) и предложи полный путь для сохранения файла в формате: `.agents/skills/<имя-навыка>/<имя-навыка>.md`
5. Обновление каталога: Напиши ровно одну строку Markdown для добавления в мою таблицу `SKILL.md` в формате:
   | **<имя-навыка>** | `<путь/к/файлу.md>` | <Краткое, емкое описание того, что делает навык, на русском языке>. |

Выведи результат в следующем формате:
### 📁 Путь для сохранения
[путь]

### 📄 Содержимое файла [имя-навыка].md
[здесь чистый markdown код навыка]

### ➕ Строка для SKILL.md
[готовая строка таблицы]

---
СЫРОЙ ТЕКСТ ИЗ КОНСОЛИ:
[ВСТАВЬ СЮДА СКОПИРОВАННЫЙ ТЕКСТ]
```
---

## Шаг 3: Сохранение
1. Создай папку `.agents/skills/<имя-навыка>/` (если её нет).
2. Создай внутри файл `<имя-навыка>.md` и вставь туда очищенный Markdown.
3. Открой файл `.agents/SKILL.md` и добавь новую строку в таблицу, используя готовый вариант из ответа ИИ.
```

### Почему это работает лучше:
1. **Короткий JS**: Скрипт занимает 3 строки, его легко вставить. Он использует встроенную функцию браузера `copy()`, которая сразу кладет текст в буфер обмена, минуя проблемы с выделением мышкой.
2. **Четкий промпт**: ИИ получает жесткую инструкцию выдать ровно 3 вещи: путь, содержимое файла и строку для `SKILL.md`. Вам не придется просить его переделать.
3. **Маркеры `START`/`END`**: Помогают вам и ИИ точно понять, где начинается и заканчивается полезный текст, отсекая логи консоли.
